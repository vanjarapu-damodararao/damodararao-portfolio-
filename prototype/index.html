02 About

Beyond code. Beyond design.

I'm Damodara Rao, a Creative Web Developer passionate about building modern digital experiences through thoughtful design, clean development and interactive technologies.

“Structure first. Detail always. A website should feel as considered as it looks.”

Background / what I do now

I build responsive websites with WordPress and Framer, and hand-code with HTML, CSS, JavaScript and PHP. add years & context

Approach / how I build

Semantic structure first, then a careful visual layer, then behaviour. Every layer stays clean so the site is easy to grow and maintain.

Creative technology / what I'm exploring

I'm currently learning React and exploring GSAP and Three.js, the tools behind the interactive building at the top of this page.

User experience / who it's for

Readable type, clear navigation and fast loading come before effects. Creativity should never cost the visitor their time.
